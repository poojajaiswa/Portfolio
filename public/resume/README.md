# Resume folder

`Pooja-Jaiswal-Resume.pdf` in this folder is a **placeholder**.

Replace it with the real resume PDF and keep the filename exactly the same —
every "Download Resume" button on the site points at
`/resume/Pooja-Jaiswal-Resume.pdf`, so no code change is needed.

To use a different filename, update `resumePath` in `lib/config.ts`.
