# Images folder

**Profile photo (optional).** Drop a square image here as `profile.jpg`
(600×600 or larger, under ~300 KB), then set this in `lib/config.ts`:

```ts
profilePhoto: '/images/profile.jpg',
```

The About profile card then shows the photo inside a gradient ring. While
`profilePhoto` is an empty string, an elegant "PJ" monogram is shown instead —
so the site looks finished either way.
